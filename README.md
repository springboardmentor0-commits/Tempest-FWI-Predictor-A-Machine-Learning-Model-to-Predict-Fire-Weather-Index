# Tempest-FWI-Predictor-A-Machine-Learning-Model-to-Predict-Fire-Weather-Index
🔥 Tempest: FWI Predictor

A Machine Learning Model to Predict Fire Weather Index

📌 Overview

Tempest: FWI Predictor is a machine learning-based web application that predicts the Fire Weather Index (FWI) using meteorological inputs. The model helps in assessing fire risk levels, which can be useful for forest management and disaster prevention.

🚀 Live Demo

👉 Deployment Link:
https://tempest-fwi-predictor-a-machine-learning-pw52.onrender.com/

🧠 Features
Predicts Fire Weather Index based on input parameters
User-friendly web interface
Built using Flask framework
Real-time prediction results
Lightweight and easy to deploy
📊 Input Parameters

The model takes the following inputs:

Temperature
Relative Humidity (RH)
Wind Speed
Rainfall
FFMC (Fine Fuel Moisture Code)
DMC (Duff Moisture Code)
DC (Drought Code)
ISI (Initial Spread Index)
🛠️ Tech Stack
Frontend: HTML, CSS
Backend: Flask
Machine Learning: Scikit-learn, Pandas, NumPy

📈 How It Works
User enters weather-related parameters
Data is processed and sent to the trained ML model
Model predicts the Fire Weather Index
Result is displayed on the web interface
