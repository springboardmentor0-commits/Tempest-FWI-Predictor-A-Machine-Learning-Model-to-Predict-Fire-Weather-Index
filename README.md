## 📌 Overview
- Tempest: FWI Predictor is a machine learning-based web application.
- Predicts Fire Weather Index (FWI) using meteorological inputs.
- Helps assess fire risk levels.
- Useful for forest management and disaster prevention.

## 🚀 Live Demo
- Deployment Link: https://tempest-fwi-predictor-a-machine-learning-pw52.onrender.com/

## 🎯 Features
- Predicts Fire Weather Index based on input parameters
- User-friendly web interface
- Built using Flask framework
- Real-time prediction results
- Lightweight and easy to deploy

## 📊 Input Parameters
- Temperature
- Relative Humidity (RH)
- Wind Speed
- Rainfall
- FFMC (Fine Fuel Moisture Code)
- DMC (Duff Moisture Code)
- DC (Drought Code)
- ISI (Initial Spread Index)

## 🛠 Tech Stack
- Frontend: HTML, CSS
- Backend: Flask
- Machine Learning: Scikit-learn, Pandas, NumPy

## ⚙️ How It Works
- User enters weather-related parameters
- Data is processed
- Sent to trained ML model
- Model predicts Fire Weather Index
- Result displayed on web interface

## 📌 Use Cases
- Forest fire risk prediction
- Environmental monitoring
- Disaster management systems
- Research and academic projects
